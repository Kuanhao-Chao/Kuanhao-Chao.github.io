[LiftOn v1.0.10](https://github.com/Kuanhao-Chao/LiftOn) builds on v1.0.9's whole-genome robustness with a third best-of-outcome merge candidate (miniprot's native model, adopted only when it strictly improves the emitted protein and is strand-consistent), a divergence-adaptive miniprot-only rescue floor that recovers more genuinely-missing genes at large evolutionary distance, coordinate-independent structural evaluation metrics, and containment-normalization and write-guard fixes that let previously-crashing full RefSeq and cross-species genomes complete and validate cleanly. It is now at or above the previous stable release on every whole genome both versions completed. This release also fixes `pip install lifton` itself: an unmaintained dependency's installer tried to download a file that no longer exists, which had been failing for anyone installing into a clean environment. The [post](/posts/lifton-v1-0-10/), [technical report](/reports/lifton-v1-0-11-technical-report/), [code](https://github.com/Kuanhao-Chao/LiftOn), and [documentation](https://khchao.com/LiftOn/) are available.
